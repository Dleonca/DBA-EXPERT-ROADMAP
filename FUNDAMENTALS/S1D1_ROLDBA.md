
# Database Management
- Security
- Availability
- Performance
- Maintenance 
- Integrity 
- Recoverability

## Responsabilidades
### Installation and Configuration
- Instalar el motor de bases de datos
- Configurar parametros del servidor
- Crear instancias de BD
- Configurar conexiones
- Administrar  almacenamiento
- Aplicar actualizaciones y parches

### Security Management and Users
- Crear usuarios y roles
- Asignar permisos y revocar permisos
- Aplicar el principio de minimo privilegio
- Gestionar Autenticación
- Auditar Accesos y actividades
- Proteger informacion sencible

### Backup and Recovery
- Fallos del servidor
- Daños en discos
- Eliminacion de registros por accidente
- Errores de configuracion
- Ataques informaticos
- Desastres fisicos
 #### CONCEPTOS
 - Full backup
 - Incremental backup
 - Diferencial backup
 - PITR point in time recovery
 - Restauracion de base de datos
 - Politicas de retencion

### Performance Tuning
- Analizar consultas SQL
- Identificar Consultas lentas
- Revisar indices
- Analizar planes de Ejecución
- Detectar Bloqueos
- Revisar consumo de CPU y memoria
- Optimizar configuraciones 
- Analizar Concurrencia
#### CONCEPTOS
 - Explain and explane analize
 - indices B-tree
 - Query Optimization
 - Executions Plans
 - Database Monitoring

### Monitoring and Maintenance
- Monitorear conexiones
- Revisar errores
- Controlar espacio de almacenamiento
- supervisar CPU y almacenamiento
- Identificar consultas problematicas
- Revisar logs
- Aplicar mantenimiento preventivo

### High availability wand disaster recovery
- replication
- primary and stand by servers
- failover
- clustering
- Load Balancing
- disaster recovery


### Database Design
- modelado de datos
- Normalizacion
- relaciones entre tablas
- claves primarias y foraneas
- restricciones (constraints)
- indices
- particionamiento de tablas
